# ⬡ Research — Stock Radar Weekly

Automated institutional-grade stock analysis pipeline. Generates weekly reports → saves as JSON → pushes to GitHub → triggers Vercel deployment.

---

## How it works

```
Claude (scheduled) → /analyze TICKER → JSON report → git push → Vercel deploys updated site
```

1. A scheduled task runs `/analyze TICKER` in Claude
2. The report is saved to `web/data/reports/<TICKER>_<YYYYMMDD>.json`
3. Git commits and pushes automatically
4. Vercel detects the push and redeploys the Next.js site

## Features

### Dashboard (`/`)
- **Weekly Watchlist** — All tracked stocks ranked by conviction composite score (verdict 40pts · Fed risk 20pts · internal score 20pts · momentum 10pts · TP2 upside 10pts). Cards show price, score ring, price-to-target bar, score drift badge, and Fed risk.
- **Ranking Change Table** — Every stock that has appeared in any report is clickable (not just the current top 5). Shows rank delta, score drift, TP2 upside, and the news headline that drove the change. Stocks that fell out of the watchlist remain accessible via the "View →" link.
- **Catalyst Calendar** — Chronological list of upcoming dated catalysts and estimate dates across all tracked stocks. Red ≤2 days · amber ≤7 days · blue = estimated date. Pulse animation on the soonest event. Cluster badge when 2+ events land within a 3-day window.

### Stock Report Detail (`/report/[ticker]`)
- **Hero card** — Price, verdict pill, score label, summary, EN/TH toggle, sticky summary bar while scrolling.
- **Stock Timeline** — Three animated sparklines (Score · TP2 Target · Rank) built from all `<TICKER>_*.json` snapshots. Hover any point for date + values + news headline. Lines animate in on scroll entry.
- **Catalyst Spot** — Pre-catalyst run-up pattern, historical earnings reactions, post-win/post-loss scenarios, spot sizing derivation, and comparable historical cases.
- **Entry Strategy** — 3 entry levels with PREFERRED badge, TP1/TP2/TP3 with % from preferred entry, tight + hard stop loss, R/R ratio, DCA/Lump Sum/Scale In verdict.
- **Scenarios** — Bear / Base / Bull / Moon diverging bar chart.
- **Macro** — Fed risk verdict (LOW / MEDIUM / HIGH), rate outlook, inflation note, sector impact.
- **Analyst Targets** — Named firm targets with horizontal bars showing vs preferred entry.
- **Comparable Cases** — Historical analogs with move %, days, outcome.
- **📐 Simulate Position** button → opens the position calculator for that ticker.

### Position Calculator (`/report/[ticker]/simulator`)
- Dual-mode input: dollar amount or share count.
- DCA blended entry across up to 5 price levels (weighted average).
- P&L table per exit level (TP1/TP2/TP3 and both stops) with R/R ratios.
- Scale-out planner: slider for % to sell at each TP, blended profit calculation.
- Scenario EV: enter win/base/bear/moon probabilities (must sum to 100), get expected value.
- Payoff ladder bar chart. All math runs client-side with animated counters.

### Verdict Accuracy Backtest (`/backtest`)
- Reads every report snapshot (not just latest per ticker) and computes +30d / +60d / +90d price checkpoints.
- Calibration bar chart: avg forward return and hit rate per verdict tier (BUY / HOLD / SELL / SPECULATIVE).
- "Fetch Prices →" button calls Yahoo Finance locally, caches results in `web/data/backtest-cache.json`, reloads page.
- Past checkpoints without cached prices show as PENDING with a fetch button. Future checkpoints show target date.
- Public-safe: no private data, works on Vercel (just without the live fetch button).

### Trade Journal (`http://localhost:3000/journal`) — LOCAL ONLY
- Reads and writes `private/journal.json` which is gitignored and never pushed to GitHub or Vercel.
- Log trades: ticker, catalyst type, entry price, shares, planned TP1/TP2/TP3, stop loss, notes, linked report date.
- Record exits: date, price, shares, note. Tracks partial exits; auto-closes trade when all shares exit.
- Stats: total P&L, win rate (with bar), open count, expectancy, plan adherence (% that exited at or above TP1), avg hold days.
- Win rate by catalyst type breakdown (earnings_beat, fda_decision, satellite_launch, etc.).
- Shared P&L math engine with the Position Calculator (no duplication).
- After each `/analyze`, the skill cross-checks `private/journal.json` and surfaces any open position in the Cowork console only — never in the public report JSON or HTML.

## Slash commands

| Command | Description |
|---|---|
| `/analyze <TICKER>` | Full single-stock report → saves JSON + HTML |
| `/dashboard` | Find 5 stocks with 30%+ upside → save watchlist |
| `/compare <T1> <T2>` | Side-by-side comparison |
| `/watchlist <T1> <T2> ...` | Quick scorecard table |
| `/macro` | Standalone Fed/macro snapshot |

## Report JSON schema

Each report in `web/data/reports/` follows the `StockReport` type in `web/lib/types.ts`:

- `ticker`, `companyName`, `sector`, `price`, `priceChange`
- `verdict` — `BUY | HOLD | SELL | SPECULATIVE`
- `summary` — 2–3 sentence thesis
- `catalysts[]` — upside drivers
- `risks[]` — downside factors
- `macroRisk` — Fed risk verdict (`LOW | MEDIUM | HIGH`) + rate/inflation notes
- `entryStrategy` — 3 entry levels, TP1/TP2/TP3, stop loss, one-line verdict
- `analystTargets[]` — firm, rating, price target
- `sources[]` — URLs cited in research

## Run locally

```bash
# IMPORTANT: run from inside the web/ folder, not the repo root
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Reports are read from `web/data/reports/` — add JSON files there to see them on the dashboard.

4. Every `git push` to `main` triggers a redeploy
